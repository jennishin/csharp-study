# C# Week 1

## 구현한 기능

- 1~100 사이의 랜덤 숫자 생성
- 사용자 숫자 입력
- UP / DOWN 판정
- 정답을 맞힐 때까지 반복
- 시도 횟수 기록
- 게임 재시작 기능
- 메서드를 이용한 메뉴 / 게임 로직 분리

## 배운 점 / 막힌 점

배운 점: 일단은 C#이 닷넷 기반이라는 점을 알 수 있음. 그리고 VS를 처음 썼는데 아주 똑똑한 IDE라 내가 똑똑해지려면 이 기능을 끄고 했어야만 했음. 또한 모르는 것이 아주 많은 것 같아서 더 배워야할 것 같음. 그리고 메서드로 만드는 것도 배움. 프로그래밍 안하다가 하니까 잘 못푸는 것 같아서 조금 슬펐다. 앞으로 더 열심히해야지.
막힌 점: 일단 메서드로 하는데서 좀 막혔고, 출력 형태를 조정하는거나 사소하게 난수 만드는 것까지 모르는게 많았었음. 하지만 잘 해냈다!
